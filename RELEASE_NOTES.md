# v1.0.0

Initial public reproducibility release.

- includes raw Direct-WENO trajectories for the N=800, N=1600 and N=3200 checks;
- includes the stored Petrov–Galerkin trajectories used by the final comparison;
- recomputes the N=3200 core reference and signed-flux control;
- recomputes the absolute-flow full-field refinement metrics;
- recomputes the sampled I2 correction from stored trajectories;
- rebuilds the final comparison table and benchmark figures;
- provides a one-command verification entry point.
