# Sources of Figures 1--3

The six source-lineage panel PDFs can be regenerated deterministically. The publication-style panels at repository root are generated by `scripts/fig*.py`; this directory verifies the independent data/code lineage of Figures 1--3.

## Figure 1: exact Petrov--Galerkin symbol and filters

- Script: `fig01_pg_symbol_filters.py`
- Data: `data/fig1_pg_symbol_filters.csv`
- Generalized-alpha calculation: canonical `ga_rho` imported from `reproducibility/jacobian/jacobian_core.py`
- Important exclusion: no call to `step_GA` or `step_GA_fast`

## Figure 2: Jacobian mesh scaling

- Script: `fig02_jacobian_h3_scaling.py`
- Data: `data/fig2_jacobian_h3_scaling.csv`
- Provenance: byte-identical to `reproducibility/jacobian/generated/jacobian_mesh_scaling.csv`
- The midpoint column is `M1_amp`; the stale historical name `midpoint_amp` is not used.

## Figure 3: corrected damping tradeoff

- Script: `fig03_controlled_damping_tradeoff.py`
- Data: `data/fig3_controlled_damping_fine_corrected.csv`
- Provenance: byte-identical to `reproducibility/generalized_alpha/results/fig3_right_corrected.csv`
- Only the corrected fine-grid case is plotted. The old `N=100` screening aggregate is not read by the script.

## Regenerate and verify

```bash
python regenerate_and_verify.py
```

A successful run prints `FIGURE_TRACEABILITY_OK`, checks the Figure 2 and Figure 3 data lineage, excludes the defective nonlinear generalized-alpha stepper from Figures 1--2, and regenerates all six source-lineage PDFs.
